# Quotation Manager - React frontend

Vite + React 18 + React Router. Talks to the quotation backend (`/api/v1`). No UI library, one CSS file.

## Run
```bash
# 1. backend running (npm run seed && npm run dev in the backend folder, port 5700)
npm install
cp .env.example .env        # VITE_API_URL=http://localhost:5700/api/v1
npm run dev                 # http://localhost:5173
```
Log in with the seeded `admin@company.com` / `Admin@12345`.
For another address, add it to `CLIENT_URL` in the backend `.env` (CORS) and rebuild with `npm run build` (output in `dist/`).

## What it does
| Screen | Highlights |
|---|---|
| **Quotation builder** | Customer, items (search the catalogue or type a custom item), per-line discount, charges, overall discount, GST on/off, inclusive/exclusive prices, place of supply, terms, design choice. **Totals are calculated by the server on every change** (`POST /quotations/calculate`) and the exact same body is saved, so the screen and the saved quotation can never differ. |
| **Quotation page** | **Design** tab shows the quotation rendered in your own layout; **Download Word / Excel / HTML** (the layout's own format) and **Download PDF**. Tabs for details, versions, activity. Send / accept / reject / cancel / revise / duplicate follow the backend's status rules. |
| **Quotation designs** | Upload a Word or Excel design, or build an **HTML design with live preview** while typing. Preview with sample figures, set default, replace file, download starters, and a tag reference (generated by the backend). Wrong tags are rejected with the reason. |
| Customers | GSTIN is checked as you type and fills the state. |
| Items, Terms, Company | Catalogue (HSN/SAC, rate, GST), reusable terms, GSTIN / bank / numbering / defaults / logo. |
| Super admin | Company picker at the top; every request is then sent with `?companyId=`. |

## How "show the design" works
- **HTML design** - shown in an `<iframe sandbox>` (no scripts can run, whatever an uploaded design contains).
- **Word / Excel design** - browsers cannot display these, so the server converts the filled file to PDF for the preview (needs LibreOffice on the server; without it you get a clear message and the download button still works).
- Downloads use `fetch` with the bearer token (a plain link cannot send it) and save the blob under the file name the server chose.

## Tests
```bash
npm test      # needs the backend running; they are skipped (not failed) if it is not reachable
```
27 tests: pure logic (formatting, payload building, HTML-designer preview) plus flows driven through the real UI against the real backend
(login, build a quotation with live totals, save, see the design, download, designer preview, GSTIN auto-fill).
Set `TEST_API_URL`, `TEST_ADMIN_EMAIL`, `TEST_ADMIN_PASSWORD` if your backend differs from the defaults.
